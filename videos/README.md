# Supporting Information videos

The three videos submitted with the article. Each was cut from the rig's own recording of
the session, with the tracking overlay (trial number, running score, current goal) drawn
from the same data that is in `../data/`. Legends are the ones in the manuscript.

## Video S1. Basic structure of the 2S2C task.

Example trials from a PI+VC rat on its fifth acquisition session: placement on the maze, two consecutive trials from the proximal and distal start arms with the return to the start arm between them, and four consecutive correct trials from a VC rat with the landmark in four different positions. The PI condition uses the identical trial structure with the monitors dimly backlit. Real time; the overlay shows trial number and running score.

Source sessions:

- CM011 (PI+VC), Acquisition session 5, 2023-07-07
- CM056 (VC), Acquisition session 7, 2023-12-04

## Video S2. Deliberation on the first Novel Route trial.

A familiar-route trial, the first Novel Route trial (trial 17) and the last Novel Route trial (trial 40) from one PIPI rat and one VCVC rat. On trial 17 the PI-trained rat shuttles between the novel start arm and the maze center for more than 30 s before choosing, whereas the VC-trained rat runs without pausing to the well that the trained turn sequence would have led to. By trial 40 the PI-trained rat takes the direct novel route while the VC-trained rat still repeats the trained sequence. Clips end at the first well visited.

Source sessions:

- CM044 (VC), Novel Route session 6, 2023-10-26
- CM050 (PI), Novel Route session 4, 2023-11-20

## Video S3. Perseveration during the Reversal probe.

A pre-reversal familiar trial, the first Reversal trial (trial 17) and the last trial of the session from one PIPI rat and one VCVC rat, each shown in full; the asterisk marks the current goal. On trial 17 both rats run first to the former goal. By its last trial (trial 40) the PIPI rat, having reached criterion, runs directly to the new goal, whereas the VCVC rat still visits the former goal first on its 80th trial and never reached criterion.

Source sessions:

- CM038 (VC), Reversal session 8, 2023-10-12
- CM052 (PI), Reversal session 9, 2023-11-25
